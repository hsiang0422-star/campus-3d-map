# 臺南特教校園 3D 地圖

羊毛氈風格的校園 3D 互動模型，教學大樓依 1–4 樓平面圖分層建模。

- 拖曳旋轉、滾輪或雙指縮放，點建築或教室查看說明
- 「教學大樓樓層」可切換外觀、1F–4F、分層展開
- 「危險角落」按鈕可顯示或隱藏校園危險角落編號
- 「無障礙設施」按鈕可顯示學校無障礙地圖標示的出入口、坡道、電梯、廁所、停車位與無障礙通路
- `accessibility.html`：以學校無障礙平面圖（`access-plan/`）為底圖的獨立無障礙 3D 地圖

位置依平面圖比例估算，供導覽與簡報使用，非實測尺寸。

開啟方式：直接用瀏覽器開啟 `index.html`，或使用本儲存庫的 GitHub Pages 網址。

完整的需求、修改紀錄與「如何在另一台電腦繼續修改」請看 [對話紀錄與修改說明.md](對話紀錄與修改說明.md)。
